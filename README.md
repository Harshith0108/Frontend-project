# 🕒 Procrastination Tracker

A minimalist app designed to help users identify procrastination habits, track time spent on tasks, and stay productive with visual progress and reminders.

---

## 🚀 Overview

The *Procrastination Tracker* is a simple yet effective task management tool with built-in time tracking and procrastination logging. It helps users reflect on their delays, manage their focus, and track productivity through a clean interface.

---

## ✅ Features

### 1. 📝 Task List

* Add new tasks with a name.
* Mark tasks as complete with checkboxes.
* View a clear list of all tasks and their statuses.

### 2. ⏱ Time Tracking

* Start/Stop timer for each task.
* Automatically track and display the total time spent on a task.

### 3. 🐌 Procrastination Log

* If a task is marked incomplete or delayed, log a reason.
* Choose from simple predefined options (e.g., "Distracted", "Lack of motivation", "Busy with other things").

### 4. 📈 Progress Tracker

* Track the number of completed vs. pending tasks.
* Visual progress bar to show percentage of tasks completed.

### 5. ⏰ Reminders

* Set one-time reminders for delayed tasks.
* Simple alert or notification to nudge users to get back on track.

### 6. 🎨 User Interface

* Clean, distraction-free layout.
* Simple navigation focused on usability.
* Responsive/mobile-first design (optional but recommended).
